# 1mail.dev — feedback

[1mail.dev](https://1mail.dev) is free, public, inbound-only disposable email
for developers, testers, and AI agents. Any address like
`test-runner-42@1mail.dev` is an inbox the moment mail arrives for it — no
signup, no keys, no sending. Messages expire after 24 hours.

**Every inbox is public.** Anyone who knows an address can read its mail.
Never use a 1mail.dev address for anything sensitive, or for any account you
care about.

This repo is the public feedback home for 1mail.dev — issues and discussions
only. **The source code is not here** (the repo that runs the service stays
private); there is nothing to build in this repo.

## Where to post

- [File an issue](https://github.com/1maildev/1maildev/issues/new/choose) —
  bugs, mail that didn't arrive, feature ideas
- [Discussions](https://github.com/1maildev/1maildev/discussions) — questions
  and help
- [feedback@1mail.dev](mailto:feedback@1mail.dev) — email works too
- [@1maildev](https://x.com/1maildev) on X
- Abuse and takedown requests go to
  [abuse@1mail.dev](mailto:abuse@1mail.dev) — never a public issue
